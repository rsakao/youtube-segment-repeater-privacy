プライバシーポリシー

最終更新日：2026年7月26日

「YouTube 区間リピート」（以下「本拡張機能」）は、YouTube動画の指定区間を繰り返し再生するためのChrome拡張機能です。

取り扱う情報

本拡張機能は、ユーザーがYouTubeまたはYouTube Musicで区間を保存した場合に限り、次の情報を取り扱います。

  • 動画を区別するための動画IDまたは動画ページのパス
  • ユーザーが入力した区間名
  • 区間の開始時刻・終了時刻、反復回数、選択状態

再生中の動画の現在時刻は、区間の開始・終了を記録し、リピート再生を制御するために一時的に使用します。現在時刻そのものは、区間として保存した開始・終了時刻以外は保存しません。

取得方法と利用目的

これらの情報は、ユーザーが「開始を記録」「終了して保存」または編集・選択・反復回数の変更を行ったときに、拡張機能がユーザーのブラウザ内で取得します。

情報は、動画ごとに保存した区間を表示・編集し、ユーザーが選択した区間だけを繰り返し再生するという本拡張機能の機能提供のためにのみ利用します。広告配信、アクセス解析、プロフィール作成、行動追跡、または本機能と無関係な目的には利用しません。

保存場所・保存期間・安全管理

情報は、Chromeの拡張機能用ローカルストレージ（chrome.storage.local）にのみ保存されます。情報はユーザーの端末上のChromeプロファイル内に保存され、当方が運用するサーバーや第三者のサーバーには送信されません。

保存した情報は、ユーザーが動画ごとの「この動画の区間をすべて削除」を実行するまで、または拡張機能を削除するか拡張機能の保存データを削除するまで保持されます。

共有・販売・第三者提供

本拡張機能は、取り扱う情報を外部へ送信、共有、販売、貸与、または第三者へ提供しません。広告SDK、アクセス解析SDK、トラッキング技術、リモートコードも使用しません。

ユーザーによる管理と削除

ユーザーは、各動画の画面で「この動画の区間をすべて削除」を選択することで、その動画に保存した区間情報を削除できます。拡張機能を削除するか、Chromeの拡張機能データを削除することでも、保存情報を削除できます。

本ポリシーの変更

本拡張機能のデータの取り扱いを変更する場合は、このページを更新し、最終更新日を変更します。
